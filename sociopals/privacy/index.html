Sociopals Privacy Policy

Last updated October 15, 2026

Sociopals (sociopals.ruchirbhatia.com) is a team chat and project workspace built and run by Ruchir Bhatia. This page explains what information Sociopals keeps and why.

What we collect

  • Account details: your name, email address and profile picture, from the sign-in method you choose (email or Google). Sign-in is handled by Clerk.
  • What you post: messages, files, docs, tasks and reactions in the servers you join. Members of those servers can see them.
  • Connected accounts you choose to add: a GitHub access token if you connect GitHub, and AI provider API keys if you add them. Both are stored encrypted and are used only for your own requests.
  • Basic technical data needed to run the service, such as server logs.

How we use it

Only to run Sociopals: to sign you in, show your messages to the people you share them with, send notifications and reminders, and run the features you use. We don't sell your information, show ads or use it for advertising.

Google sign-in

If you sign in with Google, Sociopals receives only your name, email address and profile picture. It does not access your Gmail, Drive, Contacts or any other Google data. Use of information received from Google follows the Google API Services User Data Policy, including its Limited Use requirements.

Services that process data for us

  • Clerk (sign-in), Heroku (hosting and database), UploadThing (file storage), LiveKit (voice and video calls).
  • GitHub, only if you connect it.
  • Anthropic or OpenAI, only when you use AI features. The relevant chat context is sent with your own API key.

Deleting your data

You can delete your own messages at any time. To delete your account and its data, email bhatiaruchir04@gmail.com.

Changes

If this policy changes, the date above will change too.
